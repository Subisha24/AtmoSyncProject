# AtmoSync

A real-time IoT data engineering project built using Apache Kafka, Docker, Python, Snowflake, dbt, and Apache Superset.

## Project Objective

AtmoSync simulates IoT sensor data from shipping containers and processes it through a real-time data pipeline.

## Tech Stack

- Docker
- Apache Kafka
- Python
- Snowflake
- dbt
- Apache Superset
